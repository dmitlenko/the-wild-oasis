# The Wild Oasis

## Description

This is a website for a fictional company called The Wild Oasis. The company is a luxiourious hotel with 8 cabins. The website is designed to manage the bookings of the cabins and the cabins themselves. The website has a dashboard with statistics about the bookings.

## Preview

![The Wild Oasis](/docs/preview.png)

## Features

- Create, view, update and delete cabins
- View, update and delete bookings
- Dashboard with statistics
- Authentication and authorization
- Dark mode

## Technologies

- [React](https://react.dev/)
- [Context API](https://react.dev/reference/react/createContext)
- [React Router](https://reactrouter.com/)
- [React Hook Form](https://react-hook-form.com/)
- [TanStack Query](https://tanstack.com/query/v3)
- [styled components](https://styled-components.com/)

## Installation

1. Clone the repository

```bash
git clone https://github.com/dmitlenko/the-wild-oasis.git
```

2. Install the dependencies

```bash
cd the-wild-oasis
npm install
```

3. Run the development server

```bash
npm run dev
```

4. Open [http://localhost:5173/](http://localhost:5173/) in your browser
